# 朋友试用：先解决一个真实问题

先邀请 3—5 位朋友自愿使用两周。不收集登录邮箱，也不用公开日记。

入口：[选择 Windows / Mac 下载](download.md)。下载桌面包、解压打开、填写昵称即可；无需开发环境、无需登录。数据各自保存在电脑上，不会在群友间共享。

先做三件事：

1. 给一个项目取名，留下下一步。
2. 记录一天的经历或计划与实际。
3. 几天后回看进展，周末做一次回顾。

只收集三个反馈：哪里看不懂、哪里不好用、哪里真正帮到了你。不要求每天打卡。反馈截图遮住私人内容，不上传数据库、完整备份或日记。

## 群里可直接发
