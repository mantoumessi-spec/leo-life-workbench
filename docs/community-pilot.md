# 朋友试用：先解决一个真实问题

状态：本地版可试用；暂不推进在线邀请，不收集邮箱。

第一批先邀请 3—5 人，自愿使用两周。想参加的朋友在群里联系 Leo；按 [本地安装指南](local-start.md) 在自己的电脑上安装启动。

每个人使用自己的记录，其他群友不能看到。本地模拟登录没有密码保护，请使用自己的电脑或独立系统账号。AI 功能并非入门必需，现有 AI 账号的额度与本站托管费用分别计算。

试用时先做三件事：
1. 填一个自己的项目和下一步。
2. 记录一天的计划与实际，写一句小结。
3. 几天后回看项目有没有向前走。

只收集三个反馈：哪里看不懂、哪里不好用、哪里真正帮到了你。不要求每天打卡，也不要求上传个人日记来证明使用。

## 群里可直接发的介绍

我把自己每天在用的个人工作台整理成了开源共创版。它把项目、当天重点、计划与实际、时间分类和复盘放在一起；想尽量做得简单、有温度。

GitHub：https://github.com/mantoumessi-spec/leo-life-workbench

现在提供本地版：装好 Node.js、下载并解压代码后，可以双击安装和启动，数据保存在自己的电脑。Mac 已验证，Windows 欢迎协助首测。我想先找 3—5 位朋友一起用两周，看看它有没有真的帮上忙。有兴趣的私信我就好；不用会写代码，也不用公开自己的日记。建议和问题可以在群里聊，或者提到 GitHub Issues。
