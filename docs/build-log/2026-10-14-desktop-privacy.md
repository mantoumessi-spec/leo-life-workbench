# 从启动脚本到桌面测试版

群友希望点一个链接就能选择 Windows / Mac，不再安装 Node.js。这次将界面与本地数据库打包成独立桌面程序：数据放在系统用户目录，升级程序保留记录。下载页面区分平台，提供 ZIP 文件和 SHA-256 校验值。

先检查隐私再发布：扫描当前源码与可达历史，人工核对公开截图，验证首次打开空白状态，实际解出每个平台包的应用载荷，与审核过的构建内容比较。没有把个人记录、配置、数据库、备份或 Git 历史打进程序。两次旧提交的真实邮箱经授权替换为 GitHub 隐私邮箱；已下载副本和历史缓存不能保证撤回。

Mac Apple 芯片上实际完成打开、填写、自动保存、退出重开、更新程序保留记录、JSON 下载。实测发现桌面内部协议可能省略同源 Origin 头，已在受限内部协议桥修复，网页版原有校验不变。77 项原有测试、2 项桌面集成测试、类型检查通过。桌面测试包含新库为空、重启保留、旧版本拒绝覆盖、异源写入拒绝、草稿确认/重复确认/撤回、备份读取和事务回滚。

Windows 与 Intel Mac 已生成程序包并检查内容，但没有对应实机验收。版本按小范围预览发布，未办理开发者签名/公证，没有承诺所有电脑可以无提示安装。AI 仍需手动复制，不将私人云端插件接入给朋友。
