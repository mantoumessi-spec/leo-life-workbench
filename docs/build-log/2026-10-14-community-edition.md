# 从个人工具到朋友共创版

今天的需求：让 AI 交流群里的朋友各自使用工作台，同时一起改进工具。个人版继续保留。

本次把通用源码放进 `community/`，保留日/周规划、项目时间线、自动保存、全屏写作和复盘草稿。新用户从空记录开始，六个项目位置可改名；称呼可填写。移除了作者的业务预设、原表格入口和私人站 ID，没有引入私人应用的 Git 历史。

检查中发现旧笔记草稿的本机键没有账号前缀，朋友版现已按用户隔离。钉钉前后端默认关闭，不复用作者公司应用。

线上站仍未开放：当前环境缺少 Sites 派生工具。未更改私人站权限、数据或部署。待独立站可创建后，需要真实账号验证，再按邀请名单开放。

验证：73 项单元测试、类型检查、构建通过；真实本地接口验证两种模拟身份的记录隔离、拒绝伪造身份、草稿越权操作、冲突检测和备份恢复。浏览器验证项目改名和个人称呼。测试账号不等于线上真实账号验收。后续优先验证第一次使用是否清晰、保存是否可靠、项目回顾是否有用，不急着增加更多功能。
