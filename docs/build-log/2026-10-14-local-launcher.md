# 先让朋友在自己的电脑上用起来

用户选择先做本地版：安装可以有一点门槛，数据由自己保存，不急着托管大家的日记。

这一轮保留现有功能，增加两类日常入口：安装/启动，以及备份。启动程序检查 Node 和锁定的依赖版本，仅监听本机 5173；端口被占用时明确提示，不自动换地址。已有数据库迁移前复制备份，不清空历史。

页面新增明显的备份入口，区分普通记录 JSON 与整个数据库副本。详细说明更新时不能删除旧程序目录，以及本地模拟身份不是密码保护，系统同步盘也可能把文件上传。

验证：77 项单元测试、类型检查、构建、双模拟身份接口检查通过。Mac 实际启动与本地迁移成功；页面导出的 JSON 可解析；停机备份与源文件逐字节相同，SQLite 完整性检查通过。Windows 尚未实机验证；新系统首次安装与启动器自动打开默认浏览器行为仍待首测。启动脚本不是经过签名的桌面安装包。

线上部署暂不推进，私人工作台没有改动。下一步只收集几位朋友的安装阻力、保存体验和真实使用价值。
