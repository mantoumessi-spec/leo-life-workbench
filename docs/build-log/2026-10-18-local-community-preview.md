# 2026-10-18｜让群友各自使用，一起改进

目标是减少安装步骤，同时让记录留在使用者自己的电脑。沿用已有的桌面壳，在独立社区代码里移植新版项目表格、周复盘和 Markdown 原文读写；没有复制私人实例的数据库、日记或配置。

新增昵称引导、首次启动选择数据目录、可选关联自己的 Obsidian 日记/周记目录。日记采用版本校验；两个窗口同时修改时保留草稿并提示冲突，不静默覆盖。旧版行动数据兼容升级到版本 8，程序与数据分开，升级前保留数据库副本。

功能取舍：保留手动复制给 AI 的入口；群友版不复用作者的账号、插件或公司日历授权，不自动上传内容。六个初始项目位置是空白模板，可以自行改名。暂不做多人共享看板。

验证：87 个业务测试、3 个桌面存储测试、TypeScript 和构建通过。测试覆盖空白初始化、版本冲突、重启持久化、Markdown 保存与外部修改冲突、完整快照可读及事务回滚。浏览器预览使用独立临时数据，公开截图只用虚构内容。发布包采用程序文件白名单，并解包核对，运行数据不进入包。

Windows 与 Intel Mac 的实机验收仍待首批试用补齐；未经开发者证书签名/公证，系统可能限制首次启动。公开标注这些边界，小范围收集反馈后再迭代。
